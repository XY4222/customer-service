# DESIGN.md

## 品牌与意象
"小食铺" - 一家街角温暖小店的线上化。介于便利店明亮专业和精品零食店可爱手作之间的中间地带。
不是科技蓝的冰冷，也不是糖系粉的过度装饰，是焦糖橙+奶油米色的"刚出炉的温度"。

## Design Tokens

### 色彩
- 主色：温暖橙 `oklch(0.646 0.222 41.116)`（橘焦糖色，唤起烘焙/烤制联想）
- 背景：奶油米白 `oklch(0.99 0.02 95)`（不是纯白，有温度）
- 卡片：纯白 + 圆角 + 浅描边
- 强调：奶黄 `oklch(0.88 0.18 95)`（用于高亮标签）
- 危险：番茄红 `oklch(0.60 0.22 25)`（风控不通过）
- 成功：草绿 `oklch(0.55 0.18 150)`（风控通过）
- 边框：`oklch(0.92 0.03 95)` 极浅米色，避免硬边

### 字体
- 字体族：思源黑体（Noto Sans SC）+ Noto Serif SC 用于强调标题
- 数字/价格：等宽字体，强化"账本感"

### 圆角
- 全局 `--radius: 0.8rem`（大圆角，像饼干轮廓）
- 卡片 `rounded-2xl`，按钮 `rounded-xl`，输入框 `rounded-lg`

### 阴影
- bento 风格，柔和、轻微偏移，不抢戏

## 布局与组件

### 前台 Agent 执行页
- 左右双栏：左为对话/输入区（占 60%），右为可执行计划与执行轨迹（占 40%）
- 执行轨迹按时间线竖排：每一步一张卡片，类型色块区分（Skill=橙，Tool=奶油黄）
- JSON 输入输出用 `<pre>` 块，配 等宽字体 + 浅米背景
- 顶部 Hero 区：标题"小食铺 AI 客服"，副标"Plan + Skill 可配置执行平台"
- 用户消息：右对齐，浅橙底色
- AI 回复：左对齐，白底卡片，附风控徽章

### 后台 Skill 管理页
- 顶部标题区 + 概览（5 个 Skill，4 个 Tool，状态指示）
- 列表卡片网格：每张卡片显示 Skill 名称、描述、状态开关、模型、最后修改
- 点击卡片进入侧滑 Drawer 编辑：表单分块（基本信息 / Prompt / 模型参数 / 测试）
- 测试 Tab：输入测试问题 → 流式输出结果 → 标记 PASS/FAIL
- "运行中"指示器：当前正在被前台使用的 Skill 标绿色脉冲点

## 交互与动效
- 步骤执行有进入动画（fade + slide up，stagger 100ms）
- 执行中步骤有左侧进度条流光效果
- LLM 流式输出：打字机效果
- 开关切换：弹性曲线
- Drawer 进出：250ms ease-out

## 禁忌
- ❌ 不用纯白底 + 蓝紫渐变（AI 通用审美）
- ❌ 不用 emoji 装饰（保持专业感）
- ❌ 不用大段灰色背景区块
- ❌ 不在卡片里塞进度环/饼图（只用于关键信息）
- ❌ 不用 emoji 表情

## 文案
- 中文优先，语气像"店里的常客"，不浮夸
- 例如"已规划 6 步"而非"成功生成执行计划！🎉"
